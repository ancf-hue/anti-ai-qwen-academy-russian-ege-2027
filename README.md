## 🎯 О проекте

Одностраничный HTML-тренажёр, составленный по **демоверсии, кодификатору и спецификации ФИПИ ЕГЭ-2027 по русскому языку**. Работает полностью офлайн — достаточно открыть `index.html` в браузере.

Никаких серверов, аккаунтов, рекламы и аналитики. Ответы и прогресс хранятся только в памяти вкладки.

## ✨ Возможности

- 📝 **27 заданий** по структуре ЕГЭ-2027:
  - 26 тестовых заданий с кратким ответом;
  - 1 сочинение (задание 27, самопроверка по критериям ФИПИ).
- 🎲 **Перемешивание вариантов** — правильный ответ не всегда первый.
- 🧮 **Веса заданий**: задания 8 и 22 — по 2 первичных балла, остальные — по 1 (часть 1 = 28 баллов).
- ⏱ **Таймер экзамена** с пресетами: 210 мин / 60 мин, предупреждение и сигнал об окончании.
- ✅ **Автопроверка** тестов + учебная подсказка для сочинения.
- 📋 **Чек-лист подготовки** — 21 пункт по всем темам кодификатора.
- 🗓 **25-дневный план** повторения.
- 🌐 **RU / EN интерфейс** — переключение одним кликом.
- 📱 **Адаптивный дизайн** — десктоп, планшет, телефон.
- 🔒 **100% офлайн**, без рекламы и трекеров.
